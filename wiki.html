What Are Complex Numbers?

Introduction

A complex number is a number that can be expressed in the form \(z = a + bi\), where \(a\) and \(b\) are real numbers, and \(i\) is the imaginary unit. \(a\) is the real part, written as \(\mathrm{Re}(z)\); \(b\) is the imaginary part, written as \(\mathrm{Im}(z)\). Notice that \(b\) is a real number. It is called the imaginary part only when it is multiplied by \(i\). If \(b = 0\), \(z\) is just a real number.

Imaginary Unit

The imaginary unit \(i\) represents \(\sqrt{-1}\), so \(i^2 = -1\).

Conjugate

\[ \begin{aligned} z &= a + bi \\ z^* &= a - bi \end{aligned} \]

Here z and z* are conjugates. They are formed by flipping the sign of the imaginary part.

Complex Plane

Complex plane is composed of three structures: horizontal x-axis is the real axis showing the real part of a complex number; vertical y-axis is the imaginary axis showing the imaginary part of a complex number; origin is the point \((0,0)\) where two axis cross.

Polar Equations

Polar Form

\[ z = r(\cos\theta + i\sin\theta) \]

Polar Coordinates

\[ x = r\cos\theta, \quad y = r\sin\theta \]
\[ r = \sqrt{x^2 + y^2}, \quad \tan\theta = \frac{y}{x} \]

Operations

Cartesian Form

Addition

\[ (a + bi) + (c + di) = (a + c) + i(b + d) \]

Subtraction

\[ (a + bi) - (c + di) = (a - c) + i(b - d) \]

Multiplication

\[ (a + bi)(c + di) = (ac - bd) + i(ad + bc) \]

Division

\[ \frac{a + bi}{c + di} = \frac{(a + bi)(c - di)}{(c + di)(c - di)} = \frac{ac + bd}{c^2 + d^2} + i\frac{bc - ad}{c^2 + d^2} \]

Trigonometric Form

\[ r = \sqrt{a^2 + b^2} \]
\[ \tan \theta = \frac{b}{a} \]
\[ z = r i \]

Addition

\[ z_1 + z_2 = r_1(\cos\theta_1 + i\sin\theta_1) + r_2(\cos\theta_2 + i\sin\theta_2) \]

Subtraction

\[ z_1 - z_2 = r_1(\cos\theta_1 + i\sin\theta_1) - r_2(\cos\theta_2 + i\sin\theta_2) \]

Multiplication

\[ z_1 z_2 = r_1 r_2\big(\cos(\theta_1 + \theta_2) + i\sin(\theta_1 + \theta_2)\big)=r_1r_2cis(\theta_1+\theta_2) \]

Division

\[ \frac{z_1}{z_2} = \frac{r_1}{r_2}\big(\cos(\theta_1 - \theta_2) + i\sin(\theta_1 - \theta_2)\big) = \frac{r_1}{r_2}\,\mathrm{cis}(\theta_1 - \theta_2) \]

De Moivre's Theorem

The Formula

De Moivre states that for any real number \(x\) and integer \(n\):

\[ (\cos\theta + i\sin\theta)^n = \cos(n\theta) + i\sin(n\theta) \]

De Moivre's theorem is an extension of multiplication. It can be represented as two complex number multiply together.

\[ (\cos x + i\sin x)(\cos x + i\sin x) = \cos(x+x) + i\sin(x+x) = \cos 2x + i\sin 2x \]

If you do this for \(n\) times, you are adding the angle \(x\) for \(n\) times. Therefore, raising the expression to \(n\) power is simply multiplying the angle by \(n\).

Powers

Similar to the original form, you simply need to raise the magnitude to the \(n\)-th power as well which is \(r^n\).

\[ z^n = r^n \left(\cos(n\theta) + i\sin(n\theta)\right) \]

Roots

\[ z_k = r^{1/n} \left( \cos\frac{\theta + 2k\pi}{n} + i\sin\frac{\theta + 2k\pi}{n} \right), \quad k = 0, 1, 2, \dots, n-1 \]

According to fundamental algebra, any non-zero number has exactly \(n\) distinct \(n\)-th roots. For instance, what is \(\sqrt[3]{8}\), you will answer 2. But 2 is only one root of it, the other two are complex number. The root is a reverse of multiplication. \(z^n = r\) and \(z = \sqrt[n]{r}\). For argument, we use \(n\) to multiply the angle in multiplication. Here, we do it inversely by dividing \(n\) to the angle, \(\varphi = \theta/n\). But this can only give out one angle. We need to add \(2\pi k\) on it. Knowing that adding a full rotation of \(2\pi\) (\(360^\circ\)) will lands at the same spot, there will exist different angle when you divided by \(n\).

Extension

Example:

Suppose \(n = 3\) and \(\theta = 0^\circ\)
First root (\(k = 0\))
\(\dfrac{0^\circ}{3} = 0^\circ\)
Second root (\(k = 1\))
\(\dfrac{0^\circ + 360^\circ}{3} = 120^\circ\)
Third root (\(k = 2\))
\(\dfrac{0^\circ + 720^\circ}{3} = 240^\circ\)
And what if we keep going?
Fourth root (\(k = 3\))
\(\dfrac{0^\circ + 1080^\circ}{3} = 360^\circ = 0^\circ\)

This is because the number of \(k\) is equal to \(n\). There will simply be adding \(360^\circ\) to the original angle which is the exact same angle. That's why we only need \(k = 0, 1, 2, \dots, n-1\).
